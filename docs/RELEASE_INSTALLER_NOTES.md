Windows x64 安装包。下载 `.msi` 文件后运行安装；`SHA256SUMS.txt` 提供文件校验值。

安装包在 Windows runner 上完成安装、随包文件检查、本地视频解析与下载、升级及卸载测试。升级测试使用同一源码构建的旧版本号安装包，验证 Windows Installer 升级机制；它不代表所有历史版本的数据迁移都已测试。

安装包未使用代码签名，Windows 可能显示“未知发布者”。更新时下载新版本 MSI 覆盖安装；当前不提供应用内自动更新。

自动检查的范围和安装包哈希见 `release-evidence.json`。界面人工检查、真实网站下载及所有历史版本设置迁移未自动验证，使用时发现问题可反馈。

随包包含第三方许可证文本及来源记录。部分运行工具的对应源码和构建资料核查尚未完成，详见附件 `runtime-source-review.json` 和 `runtime-redistribution-audit-20261004.md`；不将文件收集成功视为完整许可证验收。
