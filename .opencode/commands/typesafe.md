---
description: 使用 TypeSafe 设计或执行 AI 结构化判断，复用项目本地密钥
---

使用 skill 工具加载 `typesafe-ai`，按其规则处理以下任务：

$ARGUMENTS

实际调用 TypeSafe API 时，由执行请求的进程读取当前项目根目录 `.env.local` 中的 `TYPESAFE_API_KEY`，或使用该进程已有的同名环境变量。通过程序解析并仅在进程内使用密钥；不要用文件读取工具将 `.env.local` 放入模型上下文，不输出密钥、认证请求头或包含密钥的异常，不将密钥写入源码、命令参数或报告。缺少配置时只报告缺失变量名。

仅在任务需要时调用 API；纯设计讨论无需发起请求。项目内容的发送范围遵循当前任务授权。
